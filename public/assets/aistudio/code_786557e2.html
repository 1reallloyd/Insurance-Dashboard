Frequently Asked Questions

How does the Claims Trend chart calculate monthly volume?

The claims trend aggregates all bound and filed notices of loss across Auto, Home, Health, and Commercial categories using timestamped ISO transaction feeds.

What criteria flags a claim for fraud?

An ensemble model checks VIN duplicates, geo-spatial collision anomalies, telematics shock sensor discrepancies, and provider medical billing clustering.

Can I export reports into my core policy system?

Yes, our REST API supports automatic export directly to Guidewire ClaimCenter, Duck Creek, and custom SQL databases.
